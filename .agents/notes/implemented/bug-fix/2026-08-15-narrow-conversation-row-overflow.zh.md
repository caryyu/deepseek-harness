# Agent Note：窄会话行折叠页头工具并截断模型名称

Status: implemented

[English](2026-08-15-narrow-conversation-row-overflow.md) | 中文

## 问题

在手机宽度（约 375–430px 视口）的会话行上，两个固定宽度控件会溢出会话列。Session Header 中 111px 的 `Session log` 胶囊位于最右侧 `flex: none` 的工具簇里，被推出列边缘；编辑器的尾随簇（上限 220px 的模型触发器、上下文仪表、发送按钮）同样拒绝收缩，导致模型名芯片溢出、发送按钮离开卡片。模型触发器本来就有省略号 CSS，但省略号只在触发器真正失去宽度时才会生效，而不可收缩的尾随簇永远不会让它发生。

## 决策

Session Header 标题行成为尺寸容器（`container-type: inline-size`），session-log-export 的页头操作在匿名 `@container (max-width: 480px)` 查询下切换形态：111px 胶囊隐藏，由 32px 省略号触发器取代；点击它打开共享的 Menu 原语下拉，其中唯一一行就是同一个 `Session log` 操作（下载图标加标签，下载进行中时禁用，两个触发器都带 `aria-busy`）。切换纯由 CSS 完成，因此两种形态不会在同一行宽下共存；这个下拉也是未来其他页头工具可以共用的溢出座位。胶囊标签从硬编码英文移入包的语言命名空间（`action.sessionLog`）；英文界面文案不变。

编辑器行的尾随簇改为可收缩（`flex: 0 1 auto` 取代 `flex: none`），因此在宽度压力下模型触发器让出空间，其已有的省略号会截断模型名称。在行的挤压点（460px 容器查询，与相邻 PermissionSelect 折叠相同的阈值）上，触发器完全隐藏模型名称，只保留 effort 级别作为唯一标签——被挤成残片的名字比完全不显示更糟。只有带 effort 跨度的触发器才隐藏名称：无推理能力的模型保留名称作为唯一标识。完整标签仍可通过触发器的 `title` 与 `aria-label` 查看。

## 备选方案

- **用视口媒体查询代替容器查询**：否决——会话列宽度不等于视口宽度（侧栏、分栏），视口断点要么触发太晚，要么在列仍有空间时就把胶囊折叠掉。容器查询针对真正溢出的那一行做出反应。
- **用纯图标胶囊代替下拉**：否决——它在窄行上隐藏标签且没有可达的操作路径；省略号触发器只需一次点击就能到达同一个带标签的操作。
- **收缩胶囊文字**：否决——带标签的 111px 胶囊就是设计本身；把它挤成不可读的残片只是用一种溢出换另一种。

## 后果

手机行保留每一个可达控件：Session 日志操作只在窄行上多一次点击，模型芯片只显示 effort 级别（名称隐藏），而发送按钮始终留在卡片内——省略号覆盖行内仍有空间的时间段。宽行在行为与布局上完全不变——容器查询只匹配窄行，尾随簇只在行真正放不下时才收缩。阈值是容器宽度（页头 480px、编辑器行 460px）而非视口宽度，因此窄桌面面板也会同样适配。e2e 可访问性金样（在 1680px 下采集）不受影响；溢出触发器只在容器查询命中时渲染，其余时间为 `display: none`。
